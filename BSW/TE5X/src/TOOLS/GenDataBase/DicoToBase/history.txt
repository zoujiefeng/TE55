DicoToBase
-------------
This tool is used to generate winades and genebase txt files from dictionary txt files
It replaces Projet "Winades and Genebase txt files generation" step.

This tool does NOT generate *2.txt files (no BD2 support), therefore it requires Genebase S_50 or more recent.

Applicable documents
--------------------
Requirements : V01 NT 10 02934 - USER REQUIREMENTS FOR A DICTIONARY TO GENEBASE CONVERTER
User manual :  V01 NT 11 01453 - Dictionary To Genebase (DicoToBase) User Guide
