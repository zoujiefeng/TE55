# 变更履历

本文件记录项目的所有重要变更，格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，版本管理遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [未发布]
### 新增
- 新增StayInBoot超时时间，最多停留20S，在检测到StayInBoot请求时启动计时，启动擦除或写入时停止计时
- 新增**编程会话**跳转**默认会话**的标记功能，标记时发送挂起，通知APP进行积极响应
   - 文件：InfineonLib\Infra\Integration\Bsw\Dcm\integration\DcmAppl_DcmGetSesChgPermission.c
- 新增DID DFEB，DFEC
- 新增手动Swap例程
- 新增编译阶段的数组长度检查宏

### 变更
- 整理UDS例程相关文件的代码格式
- 修改ISOLAR工程配置，不再生成ComM、EcuM的代码
- 修改NvM配置代码，将Boot相关的独立配置单独拆分隔离，便于同步APP的NvM
   - 新增NvM Block相关的头文件
- 将**客制流程**和**内部流程**进一步拆分
   - 安全算法
   - DID相关内容
   - 修改27服务诊断规则，走客制流程时不再对内部安全等级作积极响应

- 客制流程变更，修改真实性完整性校验算法

### 废弃
- 删除EcuM相关的集成代码，Boot暂不需要

### 移除
- 即将移除的功能。

### 修复
- 修复多路CAN刷写功能中01通道模式读取被异常覆盖问题

### 安全
- 待发布的安全更新。
